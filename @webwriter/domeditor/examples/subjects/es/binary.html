Cuenta como un ordenador

Un ordenador puede usar dos símbolos, 0 y 1, para representar un número. Leamos cuatro símbolos mediante sus valores posicionales.

Bastan dos símbolos

Normalmente contamos con diez dígitos, del 0 al 9. Un ordenador puede representar información con dos estados, como una señal apagada o encendida. Cada 0 o 1 se llama bit. Los grupos de bits pueden representar números y otra información.

En el sistema decimal, las posiciones valen 1, 10, 100, etc. En binario, cada valor se duplica hacia la izquierda: 1, 2, 4, 8. En esta actividad, lee el número de 4 bits de izquierda a derecha con los valores indicados. Un 1 significa «suma este valor» y un 0, «no lo cuentes».

Estos símbolos son una forma sencilla de describir los dos estados. Dentro de un ordenador real, los circuitos almacenan y procesan patrones de estados.

Suma las posiciones activadas

Para 1010, están activadas las posiciones 8 y 2. Súmalas: 8 + 2 = 10. Por tanto, el número binario de cuatro bits 1010 equivale a diez en nuestro sistema decimal. El patrón de bits no es una fila de cuatro dígitos decimales independientes: es un número con posiciones de distinto valor.

Prueba el mismo método con 0111: suma 4, 2 y 1. El cero inicial mantiene cuatro bits en cada ejemplo. Con cuatro bits se forman dieciséis patrones, desde 0000 (cero) hasta 1111 (quince).

Una pista si te atascas

Para obtener siete, activa las posiciones 4, 2 y 1: [0, 1, 1, 1]. Para una quinta posición, añade un bit al principio de bits y coloca 16 al principio de places.

Antes de sumar, escribe los valores posicionales encima del patrón. Así evitarás un error común: leer desde el lado equivocado. La posición de más a la derecha siempre vale 1; a su izquierda vienen 2, 4 y 8.

  1. Descifra 0101 sumando sus posiciones activadas.
  2. Escribe el patrón de cuatro bits para seis. Comprueba que estén activadas las posiciones 4 y 2.
  3. Compara tu método con el de otra persona: ¿por qué posición empezaste?
