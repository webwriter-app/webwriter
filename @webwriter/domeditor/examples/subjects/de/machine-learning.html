Aber was ist Machine learning eigentlich?

Computer können Bilder erkennen, große Datenmengen untersuchen oder in Spielen Entscheidungen treffen. Doch wie können sie solche Aufgaben lösen, ohne dass Menschen für jede mögliche Situation genaue Regeln programmieren müssen?

Hier kommt Machine Learning (maschinelles Lernen) ins Spiel, ein Teilgebiet der Künstlichen Intelligenz. Dabei werden Algorithmen eingesetzt, die aus Daten, Beispielen oder Rückmeldungen lernen. Sie erkennen Zusammenhänge und entwickeln daraus Modelle oder Strategien, die auch bei neuen, bisher unbekannten Situationen angewendet werden können.

Je nach Aufgabe gibt es unterschiedliche Lernverfahren: Manche lernen anhand von Beispielen mit bekannten Lösungen, andere entdecken selbstständig Muster in Daten oder verbessern ihre Entscheidungen durch Rückmeldungen über Erfolg und Misserfolg.

Allerdings funktioniert das nicht immer fehlerfrei. Wie gut ein System arbeitet, hängt unter anderem von den verwendeten Daten und dem Lernverfahren ab.

Wie funktioniert das?

Beim überwachten Lernen wird ein Algorithmus mit Trainingsdaten trainiert, für die die richtigen Ergebnisse bereits bekannt sind. Diese Daten bestehen aus Eingaben mit bestimmten Merkmalen und den zugehörigen gewünschten Ausgaben (Labels). Während des Trainings werden die Parameter eines Modells so angepasst, dass es möglichst passende Vorhersagen treffen kann. Das trainierte Modell kann anschließend auf neue, bisher unbekannte Daten angewendet werden.

Ein typisches Verfahren ist die Klassifikation. Dabei werden Daten vordefinierten Kategorien, sogenannten Klassen, zugeordnet. Bei der Bildklassifikation lernt ein Modell beispielsweise anhand beschrifteter Bilder, welche Bildmerkmale für bestimmte Objektklassen typisch sind. In der Testphase wird mit bisher nicht verwendeten Daten überprüft, wie zuverlässig das Modell neue Bilder klassifiziert. Die Qualität des Modells hängt unter anderem von der Menge, Vielfalt und Qualität der Trainingsdaten ab.

Wie funktioniert das?

Beim unüberwachten Lernen erhält ein Algorithmus Daten, für die keine richtigen Ergebnisse oder Klassenzuordnungen (Labels) vorgegeben sind. Stattdessen untersucht er die Merkmale der Daten auf Gemeinsamkeiten, Unterschiede und wiederkehrende Strukturen. Während des Trainings werden die Parameter eines Modells so angepasst, dass bestimmte Muster in den Daten erkennbar werden.

Ein typisches Verfahren ist das Clustering, bei dem ähnliche Datenpunkte zu Gruppen (Clustern) zusammengefasst werden. Beim Algorithmus K-Means wird zunächst die gewünschte Anzahl der Cluster (K) festgelegt. Anschließend ordnet der Algorithmus jeden Datenpunkt dem nächstgelegenen Clusterzentrum zu. Die Zentren werden daraufhin neu berechnet. Dieser Vorgang wiederholt sich, bis sich die Zuordnungen und Zentren nicht mehr wesentlich verändern. Das entstandene Modell besteht aus den ermittelten Clusterzentren und kann auch neue Datenpunkte diesen Clustern zuordnen. Zur Überprüfung wird untersucht, ob die gebildeten Gruppen für die jeweilige Aufgabe sinnvoll sind. Eine vorgegebene richtige Gruppenzuordnung gibt es dabei nicht.

    Wie funktioniert das?

    Beim bestärkenden Lernen lernt ein System durch die Folgen seiner eigenen Handlungen. Ein sogenannter Agent befindet sich in einer Umgebung, nimmt deren aktuellen Zustand wahr und wählt eine mögliche Aktion aus. Daraufhin verändert sich die Umgebung und der Agent erhält eine Belohnung, die positiv, negativ oder null sein kann. Während des Trainings sammelt der Agent auf diese Weise Erfahrungen. Ein Lernalgorithmus passt seine internen Bewertungen an, damit der Agent zunehmend erfolgversprechende Entscheidungen treffen kann.

    Ein häufig verwendetes Verfahren ist das Q-Learning. Dabei lernt der Agent, wie vorteilhaft bestimmte Aktionen in bestimmten Zuständen sind. Diese Bewertungen werden als Q-Werte bezeichnet und bilden das Lernergebnis. Sie werden anhand der erhaltenen und der erwarteten zukünftigen Belohnungen schrittweise angepasst. Der Lernprozess wird durch Parameter wie die Lernrate und die Wahrscheinlichkeit zufälliger Aktionen beeinflusst. Der Agent muss dabei zwischen dem Ausprobieren neuer Aktionen (Exploration) und dem Nutzen bereits erfolgreicher Aktionen (Exploitation) abwägen. Ziel ist eine möglichst gute Strategie (Policy), die langfristig eine hohe Gesamtbelohnung ermöglicht. Beim Testen wird überprüft, wie erfolgreich der Agent mit seiner erlernten Strategie handelt.
