But what actually is machine learning?

Computers can recognise images, analyse large amounts of data or make decisions in games. But how can they solve tasks like these without people having to program exact rules for every possible situation?

This is where machine learning comes in. It is a branch of artificial intelligence that uses algorithms which learn from data, examples or feedback. They recognise relationships and use them to develop models or strategies that can also be applied to new situations they have never seen before.

Depending on the task, there are different learning methods: some learn from examples with known solutions, others discover patterns in data on their own or improve their decisions through feedback on success and failure.

However, this does not always work without mistakes. How well a system works depends, among other things, on the data used and on the learning method.

How does it work?

In supervised learning, an algorithm is trained with training data for which the correct results are already known. This data consists of inputs with certain features and the matching desired outputs (labels). During training, the parameters of a model are adjusted so that it can make predictions that are as accurate as possible. The trained model can then be applied to new data it has never seen before.

A typical method is classification, which assigns data to predefined categories called classes. In image classification, for example, a model uses labelled images to learn which image features are typical of certain classes of objects. In the test phase, data that has not been used before is used to check how reliably the model classifies new images. The quality of the model depends, among other things, on the amount, variety and quality of the training data.

How does it work?

In unsupervised learning, an algorithm receives data for which no correct results or class assignments (labels) are given. Instead, it examines the features of the data for similarities, differences and recurring structures. During training, the parameters of a model are adjusted so that certain patterns in the data become visible.

A typical method is clustering, in which similar data points are combined into groups (clusters). With the k-means algorithm, the desired number of clusters (K) is set first. The algorithm then assigns each data point to the nearest cluster centre. After that, the centres are recalculated. This process is repeated until the assignments and centres no longer change significantly. The resulting model consists of the cluster centres that were found and can also assign new data points to these clusters. In the evaluation, you check whether the groups that have formed make sense for the task in question. There is no predefined correct grouping.

    How does it work?

    In reinforcement learning, a system learns from the consequences of its own actions. A so-called agent is placed in an environment, perceives its current state and chooses a possible action. The environment then changes and the agent receives a reward, which can be positive, negative or zero. During training, the agent gathers experience in this way. A learning algorithm adjusts its internal ratings so that the agent can make more and more promising decisions.

    A commonly used method is Q-learning. Here the agent learns how useful certain actions are in certain states. These ratings are called Q-values and make up the learning outcome. They are adjusted step by step based on the rewards received and the rewards expected in the future. The learning process is influenced by parameters such as the learning rate and the probability of random actions. The agent has to strike a balance between trying out new actions (exploration) and using actions that have already been successful (exploitation). The aim is to find the best possible strategy (policy) that leads to a high total reward in the long run. During testing, you check how successfully the agent acts using the strategy it has learnt.
