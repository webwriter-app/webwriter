Conte como um computador

Um computador pode usar dois símbolos, 0 e 1, para representar um número. Vamos interpretar quatro símbolos usando valores posicionais.

Dois símbolos bastam

Normalmente contamos com dez algarismos, de 0 a 9. Um computador pode representar informações com dois estados, como um sinal desligado ou ligado. Um único 0 ou 1 é chamado de bit. Grupos de bits podem representar números e outras informações.

Na contagem decimal, as posições valem 1, 10, 100 e assim por diante. No sistema binário, cada valor dobra à esquerda: 1, 2, 4, 8. Nesta atividade, leia o número de 4 bits da esquerda para a direita usando os valores abaixo. 1 significa “inclua este valor”; 0 significa “deixe-o de fora”.

Esses símbolos são uma forma simples de descrever os dois estados. Dentro de um computador real, circuitos armazenam e processam padrões de estados.

Some as posições ativadas

Para 1010, as posições 8 e 2 estão ativadas. Some-as: 8 + 2 = 10. Portanto, o número binário de quatro bits 1010 representa dez no sistema decimal que conhecemos. O padrão de bits não é uma sequência de quatro algarismos decimais separados; é um número cujas posições têm valores diferentes.

Experimente o mesmo método com 0111: some 4, 2 e 1. O zero inicial mantém quatro bits em cada exemplo. Quatro bits podem formar dezesseis padrões, de 0000 (zero) a 1111 (quinze).

Uma dica se você travar

Para obter sete, ative as posições 4, 2 e 1: [0, 1, 1, 1]. Para uma quinta posição, adicione um bit no início de bits e coloque 16 no início de places.

Antes de somar, escreva os valores posicionais acima do padrão. Assim fica mais fácil evitar um erro comum: ler pelo lado errado. A posição mais à direita sempre vale 1; à esquerda vêm 2, depois 4 e 8.

  2. Escreva o padrão de quatro bits para seis. Confira se as posições 4 e 2 estão ativadas.
  3. Compare seu método com o de um colega: por qual posição você começou?
