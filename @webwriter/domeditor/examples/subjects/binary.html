Count like a computer

A computer can use two symbols, 0 and 1, to represent a number. Let’s read four of those symbols using place values.

Two symbols are enough

We usually count with ten digits, from 0 to 9. A computer can represent information with two states, such as a signal being off or on. A single 0 or 1 is called a bit. Groups of bits can represent numbers and other information.

In ordinary counting, places have values 1, 10, 100, and so on. In binary, each place doubles as you move left: 1, 2, 4, 8. For this activity, read a 4-bit number from left to right using the place values shown below. A 1 means “include this value”; a 0 means “leave it out.”

These symbols are a human-friendly way to describe the two states. Inside a real computer, circuits store and work with patterns of states.

Add the places that are on

For 1010, the 8 and 2 places are on. Add them: 8 + 2 = 10. So the four-bit binary number 1010 means ten in our familiar decimal system. The bit pattern is not a row of four separate decimal digits; it is one number whose places have different values.

Try the same method with 0111: include 4, 2, and 1, then add. The leading zero is useful because it keeps every example four bits long. Four bits can make sixteen different patterns, from 0000 (zero) through 1111 (fifteen).

A hint if you get stuck

For seven, turn on the 4, 2, and 1 places: [0, 1, 1, 1]. For a fifth place, add a bit at the start of bits and put 16 at the start of places.

Write the place values above a pattern before adding. This makes it easier to catch a common slip: reading from the wrong side. The rightmost place is always 1; the next place to its left is 2, then 4, then 8.
