Kitchen Sink

Explore every built-in insertable element, including text and container variants. Each pair uses the editor’s two-column layout: the empty insertion state on the left and authored contents on the right. On narrow screens, the empty state comes first.

Click into an empty element to add content, edit a populated example, open a disclosure, or play the audio and video. Package widgets depend on installed packages and are not included. All samples are self-contained except the video, which loads online.
