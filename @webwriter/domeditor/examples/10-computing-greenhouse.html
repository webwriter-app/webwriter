Program a greenhouse decision

Your mission

A fictional school greenhouse uses a moisture reading from 0 to 100. The class rule is simple: if the reading is below 35, recommend watering; otherwise recommend waiting. Write and test the decision logic. The program only prints advice for this simulation; it controls no equipment.

1. Trace the rule

Follow the decision diagram for readings 20, 35, and 60. Predict which branch each takes. The arrow labels “Yes” and “No” refer to the condition in the diamond.

Text equivalent: Read moisture → Is moisture less than 35? → Yes: print Water; No: print Wait → End.

2. Run and change the program

Press Run and compare the output with your predictions. Change the reading to 35 and run again. Then try 34. Why is that pair a better boundary test than testing only 10 and 90?
