# Bundled math fonts

The formula font picker embeds these fonts in documents when selected. Both
contain an OpenType MATH table and are distributed under the SIL Open Font
License 1.1. Their copyright and license notices are included alongside them.

- [Libertinus Math WOFF2](https://mathfonts.github.io/Libertinus/libertinusmath-regular.woff2) from [The Libertinus Project](https://github.com/alerque/libertinus).
- [Noto Sans Math WOFF2](https://mathfonts.github.io/NotoSans/NotoSansMath-Regular.woff2) from [The Noto Project](https://github.com/notofonts/math).
