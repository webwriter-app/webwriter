## OTHER ACTIONS

### SETTINGS

- [ ] Open Settings; confirm Show style toolbox is absent and the Style tab remains hidden.
- [ ] Set default layout to CANVAS; create a new document, then restore DOCUMENT.
- [ ] Add a word to the local dictionary, then remove the word.
- [ ] Open Commands; start a shortcut assignment, cancel, and check the original.

### ISSUES

- [ ] Enable issue checking; check the text "This are a sentense."
- [ ] Use Retry after a loading failure; continue editing the document.
- [ ] Apply a suggested correction; check only the intended text changes.
- [ ] Dismiss an issue or accept its word; run the check again.

### VERSIONS

- [ ] Make two edits; open Versions and inspect authors and change counts.
- [ ] Preview a past change; check ordinary editing is disabled in the preview.
- [ ] Return to the current document; check its content is unchanged.
- [ ] Restore an earlier change and inspect the resulting document.

### DEVELOPER CONSOLE

- [ ] Open the console; pin/unpin it, switch tabs, then close and reopen it.
- [ ] Select a paragraph; edit Selected HTML and discard the draft.
- [ ] Edit Selected HTML again, Apply, and check the paragraph updates.
- [ ] Select a local package; inspect Metadata/Element and run Tests & Checks.

### CROSS-FEATURE TASKS

- [ ] **MULTIMEDIA GUIDE:** Create a DOCUMENT that teaches something you know. Combine headings, lists, a table, an illustrated example, audio or video, and a Details hint. Make the reading order and styling coherent; credit the sources and choose licenses.
- [ ] **VISUAL EXPLANATION:** Use CANVAS to explain a process or compare ideas. Combine text, images, shapes and a formula or website. Rework the grouping, size, rotation and stacking until the explanation is clear both up close and at Fit content.
- [ ] **SHORT PRESENTATION:** Build a SLIDES presentation for a new audience using material from your guide or canvas. Adapt copied content, add media, and revise the sequence and composition. Check that the story still works when you navigate it from start to finish.
- [ ] **PROJECT BOARD:** Plan a real project in BOARD with useful columns and cards containing mixed content. Add priorities or supporting evidence, then simulate a change of plan by splitting, copying and moving work. Keep the board understandable at a narrow window size.
- [ ] **REVISE AND RECOVER:** Take one of your documents through a substantial revision: change its structure, replace media, and rewrite a section. Use Issues to improve the text and Versions to compare and recover earlier work. Finish with the combination you prefer.
