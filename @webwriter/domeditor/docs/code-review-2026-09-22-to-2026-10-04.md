## Decisions for later review

1. **Undo HTML and participant data together.** A grouped widget action currently needs two Undo commands, temporarily leaving inconsistent state. Recommend a common group identity across participating undo stacks. Reproduced in [domdoc.ts](/Users/fsalmen/Projekte/webwriter/@webwriter/domeditor/src/domdoc.ts:978), introduced by `b6b563ab`.

2. **Give inserted snippets fresh widget identities.** Removing a widget and reinserting its saved snippet restores its old participant answers through the retained ID, although saved HTML contains defaults. Recommend fresh instance IDs with internal reference remapping; this needs an authored-identity policy. Reproduced through `getSnippet` and `insert` in [manipulation.ts](/Users/fsalmen/Projekte/webwriter/@webwriter/domeditor/src/features/manipulation.ts:1886), introduced by `6643b9cf`.

3. **Preserve column definitions when splitting tables.** The second table intentionally loses authored `colgroup` and `col` presentation metadata. Recommend copying definitions with editor markers stripped and duplicate IDs handled. The current omission is explicitly tested. Evidence: [table.ts](/Users/fsalmen/Projekte/webwriter/@webwriter/domeditor/src/features/table.ts:615), introduced by `a53866b2`.

4. **Allow editing valid native HTML attributes.** Generic tools intentionally block `details[name]` and table `headers`, `scope`, `abbr`, and `role`, although imported values survive. Recommend permitting generic edits while keeping dedicated controls simple. Evidence: [element-attributes.ts](/Users/fsalmen/Projekte/webwriter/@webwriter/domeditor/src/element-attributes.ts:175), introduced by `52bf2f99` and `a53866b2`.

5. **Isolate the large application-shell test fixture.** The full run timed out in 25 shell tests; all 25 passed together in a fresh worker. A one-gigabyte diagnostic run exhausted its heap after about 32 cases. Recommend splitting the 300-case fixture into smaller isolated files and profiling retained frame state. Simple mock cleanup did not resolve it. Evidence: [dom-editor.test.ts](/Users/fsalmen/Projekte/webwriter/@webwriter/domeditor/src/components/dom-editor.test.ts:190), [vite.config.js](/Users/fsalmen/Projekte/webwriter/@webwriter/domeditor/vite.config.js:43).
