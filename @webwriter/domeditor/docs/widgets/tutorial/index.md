# Tutorial: Ghost Disco

Build a small dance floor for a ghost. Authors can edit the invitation. Readers can make the ghost float or twirl, and two readers can share the same move.

Choose **Shared** and **Reading**, then select a move to see it on both dance floors. In **Editing**, change the invitation text.
