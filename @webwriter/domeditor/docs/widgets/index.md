# Widgets

Widgets are interactive multimedia elements that can be part of a web document. They are implemented as Web Components and distributed as npm packages.

This documentation is intended for developers. Start with the introduction, then follow the tutorial, solve a specific task with a guide, or look up an interface in the reference.

Choose **JS**, **Lit**, **React**, **Vue**, **Angular**, or **Svelte** in the header. The widget interface, authored HTML, and CSS are independent of the rendering library. The quick start and tutorial include complete sources and live examples for all six choices.
