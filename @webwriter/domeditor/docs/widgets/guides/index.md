| [Support editing](editing.md) | Adapt the interface for authors and users. | Map marker |

| [Convert & import/export](conversions.md) | Exchange content with native HTML and files. | Packing checklist |
| [Make layouts responsive](responsiveness.md) | Fit the space allocated to a widget. | Weather dashboard |
| [Localize a widget](localization.md) | Follow the document's language. | Audio transcript |
| [Support printing](printing.md) | Provide a useful paper representation. | Observation log |
| [Manage state](state.md) | Choose where state lives and expose saved settings through options and actions. | Metronome |
| [Make data reactive](reactivity.md) | Connect widgets so one updates when another publishes a new value. | Color picker and swatch |
| [Share participant data](sharing.md) | Persist data individually, for everyone, or for groups. | Tally counter |
| [Support live sessions](live-sessions.md) | Configure participant controls and show learner responses together. | Glossary controls and workshop poll |
| [Use libraries and assets](libraries.md) | Load dependencies, styles, and media. | Illustrated field guide |
| [Test, debug and optimize](testing.md) | Verify widget behavior and control what Offline HTML embeds. | Unit converter and optional simulations |
| [Migrate widget content](migrations.md) | Update content from an older version. | Glossary |
| [Publish a widget](publishing.md) | Distribute a package and embed a widget on another site. | Origami viewer and field journal |
