# Guides

These guides help you complete a specific task in an existing widget. For a first widget, follow the [tutorial](../tutorial/index.md).

| Guide | Goal |
|---|---|
| [Manage state](state.md) | Choose properties, attributes, content, or scoped data. |
| [Share participant data](sharing.md) | Persist answers individually, for everyone, or for groups. |
| [Support live sessions](live-sessions.md) | Show learner responses together in the editor. |
| [Make layouts responsive](responsiveness.md) | Fit the space allocated to a widget. |
| [Nest widgets and editable content](content.md) | Display and edit light-DOM children. |
| [Handle focus, selection and input](focus.md) | Manage widget focus, document selection, and keyboard input. |
| [Support editing and viewing](editing.md) | Adapt the interface for authors and users. |
| [Localize a widget](localization.md) | Follow the document's language. |
| [Support printing](printing.md) | Provide a useful paper representation. |
| [Use libraries and assets](libraries.md) | Load dependencies, styles, and media. |
| [Test and debug](testing.md) | Check saving, interactions, and editor integration. |
| [Publish a widget](publishing.md) | Build and distribute a widget. |
| [Migrate widget content](migrations.md) | Update content from an older version. |
